# Menu-Driven C Application (Dev-C++)

## Overview

This project is a **menu-driven C console application** developed as part of an Information Technology coursework assignment. The application demonstrates modular programming by separating functionality into multiple source (`.c`) and header (`.h`) files and integrating them into a single executable using **Dev-C++**.

The program allows users to interact with a menu, select options, and execute different functions based on their input.
