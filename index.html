Menu-Driven C Application

This project is a menu-driven console application written in C. It demonstrates modular programming using header files and multiple source files compiled into a single executable.

Features

  • Text-based menu system
  • Modular C design
  • File read and write operations
  • Single compiled executable

How to Run

This program runs locally in a terminal.

gcc main.c menu.c optionSelector.c writeFile.c readFile.c -o menuApp
./menuApp
